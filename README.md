## 🚀 Key Features of this Portfolio

- **⚡ Modern Dark & Cyberpunk Aesthetics:** Built with sleek glassmorphism, responsive glow cards, and particle background dynamics.
- **🔮 Interactive Placement Predictor Simulator:** An in-browser interactive simulator modeling real-world student academic metrics & internship parameters with ~85% accuracy.
- **💻 Recruiter CLI Terminal:** Integrated interactive terminal emulator with commands (`help`, `skills`, `projects`, `contact`, `clear`) for quick navigation.
- **📊 Interactive Skill Gauges:** Categorized visualization of technical proficiencies across Python, SQL, Java, Machine Learning, and OOPs.
- **💼 Comprehensive Experience Showcase:** Detailed breakdowns of practical training at **Innomatics Research Labs** (OpenCV & Computer Vision) and upcoming internship at **SkillDzire / APSCHE**.

## 💻 Local Setup & Development

To run this project locally on your machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/chanduk39k-ctrl/studentportfolio.git
   cd studentportfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
